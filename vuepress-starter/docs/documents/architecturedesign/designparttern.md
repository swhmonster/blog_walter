# 设计模式
- 推荐几本书及几个网站：
    - 设计模式相关书籍：
        - 《Java设计模式及实践》，卡马尔米特·辛格 艾德里安·伊恩库列斯库 路西安-保罗·托尔耶
        >比较一针见血，适合作为工具书查阅，我个人比较喜欢这种一针见血的风格，可以节约很多时间
        - 《设计模式之禅（第2版）》，秦小波
        >具有故事性，讲解有趣，没有那么枯燥，适合日常读
    - 设计模式菜鸟教程：
    
        <https://www.runoob.com/design-pattern/design-pattern-tutorial.html>
